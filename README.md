🏆 Site da Atlética UNIFEI — Campus Pouso Alegre

Site desenvolvido para a Associação Atlética Acadêmica da UNIFEI — Campus Pouso Alegre, com o objetivo de centralizar informações sobre a atlética, eventos, campeonatos e modalidades esportivas, além de permitir o envio e gerenciamento de inscrições.

📌 Sobre o projeto

O projeto foi desenvolvido como parte das atividades acadêmicas do curso de Engenharia de Software da UNIFEI.

A aplicação possui páginas públicas para apresentação da atlética e áreas que utilizam autenticação para controlar o acesso a funcionalidades administrativas.

O sistema utiliza Firebase Authentication para autenticação de usuários e Cloud Firestore para armazenamento dos dados.

🔐 Segurança

O projeto utiliza Firebase Authentication para autenticação dos usuários e Firestore Security Rules para controle de acesso aos dados.

Os usuários possuem diferentes níveis de acesso. Usuários autorizados como gestores podem acessar determinadas informações administrativas, enquanto operações sensíveis são restringidas pelas regras do Firestore.

As operações de leitura e escrita são controladas pelas regras de segurança do banco de dados.
